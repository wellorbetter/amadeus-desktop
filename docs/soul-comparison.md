# Soul 对比：我方 kurisu.md vs 开源 Amadeus 项目

> 日期：2026-08-08 · 参照仓库：[FrancescoCaracciolo/Amadeus](https://github.com/FrancescoCaracciolo/Amadeus)（GPL-3.0）
> 结论先行：**我们的 soulmd 是「数据驱动 + 安全优先」的定制版，开源 Amadeus 是「台词知识库 + 通用人格」的增强版，二者互补**。最优路径是保留我们的安全/隐私/防注入设计，吸收它的「台词风格样本 + 世界观知识」作为风格锚点。

---

## 1. 双方结构对比

| 维度 | 我方 `apps/pet-demo/soul/kurisu.md` | 开源 Amadeus（Prompts/ + Dialogues/） |
|---|---|---|
| 形态 | 单文件角色卡（2.3KB，简体中文） | 多文件：`Kurisu_EN.md`（人格）+ `Story_EN.md`（世界观 67KB）+ `SG_Dialogues_EN.md`（VN 台词 16 万字）+ `emails.json`（D-mail） |
| 人格 | 傲娇/毒舌/脑科学术语/内心独白「（…）」/1-2 句 ≤60 字 | 英式细腻描写（17 岁毕业的天才、讨厌绰号、外冷内热） |
| 台词样本 | 4 条自写示例（专注/熬夜/点评/被叫助手） | **758 条 Kurisu 原版台词**（可向量检索做 few-shot） |
| 世界观 | 无（仅身份：LabMem 004 / 冈部 / LabMem 001） | 完整 S;G 剧情摘要（分章节，可语义检索） |
| 数据接入 | **强**：聚合数据/隐私规则/防注入/不输出原始标题 | 弱：仅对话，无数据源概念 |
| 记忆方案 | SimpleMem 三阶段 + 分层记忆（设计文档） | 台词向量库 + 用户摘要 + Memoripy（向量+衰减） |
| 许可证 | 我方 MIT | GPL-3.0（台词源自 VN，版权敏感，**不可直接搬运**） |

## 2. 关键差异（我们缺什么 / 有什么）

### 我们已有、开源没有的（优势，必须保留）
1. **隐私与安全硬规则**：绝不输出原始窗口标题/URL/日记全文；聚合层才可说话。
2. **防提示注入**：`system.ts` 中的 GUARD_RULES（输入剥离 + 输出脱敏）。
3. **数据驱动触发**：TriggerEngine 策略（专注 2h / 熬夜 / 久坐 / 日记复盘 / 目标），0 token 规则预筛。
4. **成本控制**：意图感知检索 + 摘要缓存 + token 预算，原始数据永不进 prompt。
5. **中文语境**：直接输出简体中文 1-2 句，符合桌面气泡场景。

### 开源有、我们缺的（可吸收项）
1. **台词风格样本**：Amadeus 用「向量检索相似台词 → few-shot」锚定说话风格。我们只有 4 条示例，风格容易漂移。
   - ✅ 但我们**不能搬运** 758 条原版（GPL + VN 版权）。
   - ✅ 替代：**自写 30-50 条原创中文风格样本**（傲娇/科学吐槽/内心独白），按场景分类，固化进 soulmd 做 few-shot。
2. **世界观知识**：S;G 设定（LabMem、D-Mail、Reading Steiner、世界线）能让角色更立体。
   - ✅ 替代：soulmd 里加一节「世界观锚点」（原创转述，不引用原文），如 LabMem 编号、称呼习惯、世界线梗。
3. **用户长期记忆**：Amadeus 用向量库记忆用户交互。我们已规划 SimpleMem + sqlite-vec/Vectorize，尚未落地。

## 4. 结论

- **不需要推翻重写**：我们的 soulmd 定位是「有数据、有安全、有预算的桌面助手」，方向正确。
- **需要补的只有两块**：① 风格样本（原创 few-shot）；② 世界观锚点（原创转述）。两者都避免版权搬运，保留我们的安全设计。
- **记忆与循环**：Amadeus 的 Memoripy 我们不必引入；SimpleMem 三阶段 + 分层记忆已足够，下一步直接落地 trigger→agent→mem→反馈闭环。

- 桌宠内置默认人格升级：融合 Amadeus 人格特征（17 岁大学毕业的天才 / 讨厌被叫「助手」「克里斯提娜」「傲娇」/ 成熟冷静与胆怯反差 / tsundere 恼怒梗），原创中文改写，保留隐私红线与防注入规则（`apps/pet-flutter/lib/app.dart` 的 `_defaultPersona`）。
- 数据语料注入层落地：`_dataCorpus()` 在主动对话触发时把 TimeTrace 聚合数据（当前前台 / 今日活跃 / 空闲 / 切换 / 历史 3 天）拼进本次 prompt —— 会话级注入，绝不写入 soul.md；TriggerEngine 措辞由「别提数据」改为「可结合观测语料，别生硬报数」。
- `apps/pet-demo/soul/kurisu.md` 同步补充「成熟冷静 + 胆怯反差」性格维度，保持与内置默认一致。
- 原则：soul 卡只承载人格，数据语料永远外挂（运行时生成，不落盘、不入卡）。
